# vibe-mac

`vibe-mac` — безопасный установщик среды для вайбкодинга на Mac с Apple
Silicon и macOS 14 или новее. Он проверяет текущее состояние, показывает план,
делает только недостающие изменения и после каждого шага проверяет результат.
Повторный запуск продолжает незавершённую установку.

Текущая версия разработки — `0.1.0-dev`. Публичный production-релиз ещё не
выпущен.

## Что устанавливается

- Xcode Command Line Tools и Homebrew;
- Git, GitHub CLI, Ghostty, системный zsh, Oh My Zsh и Starship;
- `ripgrep`, `fd`, `fzf`, `bat`, `eza`, `jq`, `tree`, `zoxide`,
  `mise` и `uv`;
- Node.js `24.18.1` и Python `3.12.13` через `mise`;
- Claude Code, Codex, Cursor и Cursor Agent;
- локальный стартовый проект `~/dev/hello-vibe`.

С `EXTRAS=1` дополнительно ставятся Zed, Raycast и Visual Studio Code.

Установщик не принимает API-ключи и не читает файлы credential stores
напрямую; статус входа проверяют только официальные CLI. Уже существующие
пользовательские конфиги не перезаписываются целиком: в них
добавляются помеченные блоки, а исходное состояние и ownership записываются в
приватный manifest. Для уже установленных прямых пакетов нет намеренного
upgrade; при этом Homebrew может изменить транзитивную зависимость, если она
нужна новому пакету. Такая дельта попадает в итоговый отчёт.

## Требования

- Mac с Apple Silicon;
- macOS 14 или новее;
- не менее 15 ГБ свободного места;
- интернет и пароль администратора Mac;
- штатный Терминал и системный браузер для видимых подтверждений.

Intel поддерживается только как best-effort режим:
`ALLOW_UNSUPPORTED_INTEL=1`. Этот режим не входит в гарантию продукта.

## Запуск из проверенного checkout

Сначала открой Терминал и перейди в корень скачанного репозитория. Безопасно
посмотреть план без каких-либо изменений:

```bash
DRY_RUN=1 /bin/bash ./install.sh
```

Начать установку:

```bash
/bin/bash ./install.sh
```

Не закрывай Терминал во время активного шага. Если загрузка или проверка
оборвалась, запусти ту же команду ещё раз: выполненные шаги будут проверены, а
процесс продолжится с первого незавершённого.

### Флаги

| Флаг | Значение |
| --- | --- |
| `DRY_RUN=1` | Только локальная проверка и план; без записей, сети, `sudo`, GUI и входов |
| `EXTRAS=1` | Добавить согласованный набор необязательных приложений |
| `SKIP_DEFAULTS=1` | Не читать и не менять две настройки macOS |
| `ALLOW_UNSUPPORTED_INTEL=1` | Разрешить best-effort запуск на Intel |

Булевы флаги принимают только `0` или `1`.

## Где установщик останавливается

`vibe-mac` просит явное подтверждение перед:

- системным окном установки Command Line Tools;
- использованием официального установщика Homebrew и возможным запросом
  пароля Mac;
- входом в GitHub, Claude, Codex и Cursor;
- изменением двух настроек macOS;
- открытием стартовой страницы.

Входы можно отложить. Техническая установка при этом считается завершённой.
Позже их можно выполнить вручную:

```bash
gh auth login --web --git-protocol https
claude auth login
codex login
cursor-agent login
open -a Cursor
```

## Что меняется на диске

- runtime, состояние и приватные логи: `~/.vibe-mac/`;
- резервные копии: `~/.vibe-mac-backup/<install-id>/`;
- управляемые shell-блоки в `~/.zprofile` и `~/.zshrc`;
- конфиги Starship, Ghostty, `mise` и алиасов;
- только отсутствующие Git defaults;
- по отдельному согласию: автоскрытие Dock и показ расширений Finder;
- новый локальный Git-проект `~/dev/hello-vibe` без commit, remote, push или
  публикации.

Если `~/dev/hello-vibe` уже существует, его содержимое не меняется.

## Проверка, диагностика и удаление

Из checkout:

```bash
/bin/bash ./verify.sh
/bin/bash ./doctor.sh
/bin/bash ./uninstall.sh --dry-run
```

После будущей установки versioned bundle будут доступны команды:

```bash
vibe-mac-verify
vibe-mac-doctor
vibe-mac-uninstall
```

`verify` показывает ровно 12 технических критериев и итог
`N из 12 готово`. Статусы входов выводятся отдельно.

`doctor` по умолчанию только диагностирует. Команда
`vibe-mac-doctor --repair` сначала показывает ограниченный план и требует
явное подтверждение.

`uninstall` по умолчанию и с `--dry-run` только показывает план.
`vibe-mac-uninstall --apply` требует точное слово `UNINSTALL` и удаляет
лишь доказанно принадлежащие установщику неизменённые объекты. Проект,
аккаунты, credentials, Homebrew, Command Line Tools, state, логи и резервные
копии сохраняются.

Если что-то не прошло, открой
[TROUBLESHOOTING.md](TROUBLESHOOTING.md).

## Production-установка

**Production one-liner пока намеренно не опубликован: release-гейт не
пройден.** Не запускай `bootstrap.sh` напрямую из ветки разработки — в нём
находятся release-placeholder значения.

Команда появится здесь только после signed tag, immutable release, проверки
обоих SHA-256 и полного пилота на чистом Apple Silicon Mac.
