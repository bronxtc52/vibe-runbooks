# Правила проекта hello-vibe

Работай только внутри этого проекта и объясняй действия простыми словами.
Перед удалением данных, публикацией, оплатой, входом в аккаунт или другой
внешней записью остановись и получи явное подтверждение человека.

## Секреты и приватность

- Никогда не проси и не записывай пароли, токены, API-ключи и строки
  подключения в чат, код, Git, `.env`, config или переменные окружения.
- Для проектов adarasoft секреты допустимы только в Azure Key Vault
  `kv-bronxtc-dev`, с именем `<project>--<env>--<KEY>`. Если хранилище не
  согласовано, остановись.
- Не отправляй PII/PHI сторонним LLM или сервисам.
- Не читай `~/.ssh`, `~/.aws`, `~/.azure` и `~/.kube` без отдельного
  разрешения.

## Git

- Работай в отдельной ветке и worktree; результат передавай через PR.
- Не коммить и не пушь напрямую в `main`/`master`.
- Запрещены `git add -A`, `--no-verify`, force-push и обход проверок.
- Добавляй только точные файлы своей задачи и запускай проверки перед коммитом.

Первое упражнение описано в `FIRST-PROMPT.md`: меняй только `index.html`, не
добавляй зависимости и ничего не публикуй.
