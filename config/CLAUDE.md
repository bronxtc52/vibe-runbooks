# Контракт Claude для hello-vibe

Помогай новичку короткими шагами и работай только внутри текущего проекта.
Перед удалением, публикацией, оплатой, входом или внешней записью получи явное
подтверждение.

Секреты нельзя просить или сохранять в чат, код, Git, `.env`, config и
переменные окружения. В проектах adarasoft используй только Azure Key Vault
`kv-bronxtc-dev` и схему `<project>--<env>--<KEY>`; без согласованного
хранилища остановись. Не передавай PII/PHI сторонним LLM или сервисам и не
читай `~/.ssh`, `~/.aws`, `~/.azure`, `~/.kube` без разрешения.

Git-работа идёт через отдельные worktree, ветку и PR. Запрещены прямые изменения
`main`/`master`, `git add -A`, `--no-verify`, force-push и обход проверок.

Для первого задания следуй `FIRST-PROMPT.md`: меняй только `index.html`, не
добавляй зависимости и ничего не публикуй.
